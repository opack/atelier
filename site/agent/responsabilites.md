# Ce qui reste humain

atelier automatise le mécanique et le déterministe. Le reste vous appartient.

## Ce que vous ne déléguez pas

| Décision | Quand |
|---|---|
| Le périmètre : ce qu’on fait et ce qu’on ne fait pas | Intention |
| Le TDD : oui ou non | Intention |
| La signature de la spec | Signature |
| Le choix d’approche | Conception |
| La relecture des tests | Tests d’abord |
| La validation de chaque tranche | Implémentation |
| Le verdict | Clôture |
| « L’IA me ralentit-elle ici ? » | Tout le temps |

## Les zones critiques

Sur ces zones, vous écrivez ou relisez **chaque ligne** :

- paiement et abonnements ;
- concurrence et transactions ;
- règles de sécurité ;
- authentification **et autorisation** ;
- migrations de données ;
- secrets.

## Savoir expliquer chaque ligne

C’est le test final : vous devez pouvoir expliquer, à voix haute, chaque ligne que vous fusionnez. Si ce n’est pas le cas, ce n’est pas prêt.

## Préserver vos compétences

Un agent qui écrit tout fait perdre la fluence. Quelques garde-fous :

- des **exercices réguliers sans IA** (katas chronométrés) ;
- écrire **vous-même** le plan ou les tests de temps en temps ;
- en revue, se poser la question : **saurais-je l’écrire ?**
